تم تنفيذ ميزتين أساسيتين مع بعض: (1) نظام تنبيهات إلكتروني يبعت إيميل فوري لما أي منتج يوصل أو يقل عن الحد الأدنى — مش محتاج حد يفتح الداشبورد عشان يعرف، و(2) كيان "عميل" حقيقي بدل النص الحر — كل عميل ليه ملف ثابت وكل إذن صرف مربوط بيه. الميزتين مع بعض بيخلي التتبع أقوى والمسؤولية أوضح.

P1.7 — نظام التنبيهات الإلكترونية

  • يتحقق تلقائيًا من المخزون بعد كل عملية صرف
  • لو أي منتج وصل أو تحت الحد الأدنى → إيميل HTML احترافي بالعربي
  • الإيميل فيه جدول بالمنتج المنخفض + الكمية + الحد الأدنى + التصنيف
  • يعمل مع أي مزود SMTP (Gmail, Outlook, Mailgun, إلخ)
  • غير عامل — الإرسال fire-and-forget مش بيمنع عملية الصرف
  • فحص يدوي متاح عبر API للاختبار

P1.8 — كيان العميل الحقيقي

  • نموذج Client كامل (اسم، تليفون، بريد، عنوان، ملاحظات، حالة)
  • كل إذن صرف مربوط بعميل (FK في قاعدة البيانات)
  • استيراد تلقائي للعملاء الحاليين من أذونات الصرف السابقة
  • شاشة عملاء كاملة (CRUD + بحث + تفاصيل)
  • شاشة الصرف فيها dropdown للعميل + خيار اسم حر
  • 4 صلاحيات جديدة (عرض/إنشاء/تعديل/حذف)
